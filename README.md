# Microservicio Recompensa
Este microservicio se encarga de registrar todas las recompensas y dividirlas por la cantidad de jugadores de un equipo en concreto, tiene conexion con Equipo, Premio y Auditoria, el premio puede ser efectivo u objeto ya sea un copa o hardware , puede hacer cambios como guardar, crear , actualizar o eliminar y se guardara en la base de datos para tener un historial de dichos cambios

## Dependencias

* Spring Web
* Validation
* Spring Data JPA
* OpenFeign
* MySQL Driver
* Lombok
