## Microservicio Recompensa
Este microservicio se encarga de registrar todas las recompensas y dividirlas para el equipo de cada jugador de un torneo en concreto, tiene conexion con Equipo, Premio y Auditoria, el premio puede ser efectivo u objeto ya sea un copa o hardware  se puede sacar el ranking global, puede hacer cambios como guardar, generar , actualizar o eliminar y se guardara en la base de datos para tener un historial de dichos cambios

# Dependencias

* Spring Web
* Validation
* Spring Data JPA
* OpenFeign
* MySQL Driver
* Lombok
